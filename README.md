# Максим Лисевський — сайт-резюме

Живо: https://mgromov688-boop.github.io/maxim-portfolio-ua/

Один сайт, дві сторінки:

- `index.html` — резюме: досвід, стек, освіта, процес, контакти
- `roboty/index.html` — портфоліо, 9 кейсів із розбором

Мова сайту — українська. Кнопки UA / RU / EN у шапці перемикають переклад
без перезавантаження; вибір запам'ятовується. Кейси, ассети й адреси —
одні й ті самі для всіх трьох мов.

## Структура

```
assets/site.css      спільні стилі (портфоліо)
assets/resume.css    стилі сторінки резюме
assets/site.js       спільні модулі: фон героя, курсор, reveal, модалки
assets/resume.js     ефекти сторінки резюме — один слухач скролу
assets/roboty.js     прямі посилання на кейс (#case-<slug>)
assets/i18n.js       перемикач мови
assets/dict-cv.js    словник сторінки резюме
assets/dict-works.js словник сторінки кейсів
```

Словники збираються скриптом `i18n/build.py` після будь-якої правки тексту:
він перевіряє, що жодного неперекладеного рядка не залишилось.
